# Desafio Bar OO

Projeto desenvolvido como parte do curso **Formação Desenvolvedor Moderno**, com o objetivo de aplicar conceitos de **Programação Orientada a Objetos (POO)** utilizando Java.

O desafio consiste em desenvolver um sistema para calcular a conta de um cliente em um bar, considerando o valor do ingresso, os itens consumidos e a cobrança do couvert artístico.

## Sobre o desafio

No bar, os valores são definidos da seguinte forma:

* Ingresso masculino: **R$ 10,00**
* Ingresso feminino: **R$ 8,00**
* Cerveja: **R$ 5,00**
* Refrigerante: **R$ 3,00**
* Espetinho: **R$ 7,00**
* Couvert artístico: **R$ 4,00**

Quando o valor do consumo é **superior a R$ 30,00**, o cliente fica **isento do couvert artístico**.

## Objetivo

O programa recebe os seguintes dados do cliente:

* Sexo (`F` ou `M`)
* Quantidade de cervejas
* Quantidade de refrigerantes
* Quantidade de espetinhos

A partir dessas informações, o sistema calcula e apresenta um relatório contendo:

* Valor do consumo
* Valor do couvert
* Valor do ingresso
* Valor total a pagar

## Conceitos praticados

Neste projeto foram aplicados conceitos fundamentais de **Programação Orientada a Objetos em Java**, como:

* Classes e objetos
* Atributos
* Métodos
* Encapsulamento
* Métodos `static`
* Construtores
* Organização e responsabilidade de uma classe
* Convenções de nomenclatura do Java

O desafio também possui critérios específicos relacionados à utilização correta de classes, atributos e métodos, além do comportamento esperado do programa.
